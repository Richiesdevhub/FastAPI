
primera sesion.- aprendiendo a usar el paquete uv

### Como inicializar el proyecto con uv

$ uv init -your project- # Esto crea una carpeta con el proyecto

### En carpeta creada

$ cd -tu carpeta ya creada-
$ uv init .

### Agregar dependencias

$ uv add pandas

### Correr el pryecto con manejo de dependencias aisladas

$ uv add proyect.py
