Instalar uv
Inicializar archivo con uv init -nombre del proyecto- o uv init . 
para un proyecto existente
Si agregas librerias es con uv add -nombre de la libreria-
Cuando corras el archivo, usas uv run -nombre del archivo- y así uv se encarga
 de manejar todas sus dependencias
